WHAT THIS IS
A new tab page: a clock, a search box, quick links, and an optional second
screen of cards (to-dos, notes, pomodoro, calendar, weather). No account, no
server, no analytics, no remote code, no content scripts. No credentials are
needed to test it.

HOW TO TEST
Open a new tab. Scroll down for the second screen, click the clock for the
dial, gear at the bottom right for settings.

REQUIRED PERMISSIONS
storage - the user's own settings, layout, to-dos and notes. Settings and
layout use storage.sync so they follow the user's browser account; larger
data uses storage.local. Nothing is uploaded anywhere.
topSites - read once, only when the user presses "import from most visited"
in settings, to fill the quick-link tiles. Never read continuously.
favicon - site icons on quick links, from the browser's own cache via
_favicon/. Requested specifically so we do NOT fetch icons from the sites
themselves, which would disclose the user's saved sites to third parties.

OPTIONAL PERMISSIONS
tabs, bookmarks, history, sessions and downloads are all declared under
optional_permissions and requested at runtime inside a user gesture, only
when the user opens the matching feature. tabs powers the "now playing" card
(tabs.query({audible:true})) so a noisy tab can be muted; no page content is
read. The other four power the command palette (Ctrl+K), which matches
locally and transmits nothing.

OPTIONAL HOST PERMISSIONS
Requested only when the user turns weather or holidays on. open-meteo.com -
weather for a city the user typed; the geolocation API is never used.
aviationweather.gov - public-domain METAR, a measured temperature instead of
a modelled one. api.rainviewer.com - radar tiles. opendata.cwa.gov.tw - only
if the user pastes their own key. calendar.google.com - a public holiday
iCal; the user's own calendar is never touched.

Nothing is collected or sold; there is no server.
