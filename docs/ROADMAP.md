# 元件路線圖

一次做一個。每一項後面那段是動手之前必須知道的事 —— 不是風險清單，
是「這件事實際上做得到什麼、做不到什麼」，免得做到一半才發現要退回去。

## 1. 日曆元件 ← 進行中

常態是一張卡：星期、大大的日期、月份。點右上角展開成整屏的月曆，
右側是當天的行程，可以新增、刪掉。

- 行程存在 `storage.local` 的工作區裡，跟待辦、筆記同一份。
- **Google 日曆同步不在這一輪。** 那需要 `chrome.identity` 走 OAuth，
  而 OAuth client id 得由你本人到 Google Cloud Console 開一個專案申請，
  再把 client id 填進 `manifest.json` 的 `oauth2` 區塊。程式碼我可以寫，
  但那個申請只有你做得了，所以先把本機行程做完整。
- 檢視只做「月」和「議程」。日／週／年三個檢視是同一份資料換一種排版，
  真的要再加。

## 2. 番茄鐘展開

現在那張卡留著，另外做一個整屏的詳細畫面：專注／短休／長休／強力四種
時段、專案分類、今日與總計的統計圖、任務清單。

- 時段長度要變成可設定的，現在 25/5 是寫死的常數。
- 專案和統計要新的資料表（每一段專注記一筆：開始、長度、專案、任務），
  這是目前工作區裡沒有的東西，會是這一項裡最大的一塊。
- 統計圖自己畫 SVG，不裝圖表套件 —— 一根長條加一條基線，
  套件的體積比這件事本身大十倍。

## 3. 天氣元件 ← 完成

預設大小只顯示現在的天氣（等於現在右上角那塊，改成一張卡）。
拉大之後顯示所在城市的雷達回波圖。

- **Open-Meteo 沒有雷達圖。** 圖磚接 RainViewer，索引 JSON 要一個
  optional host permission；圖磚本身是 `<img>`，不需要權限。
- **底圖踩過一個坑**：原本用 CARTO 的 `basemaps.cartocdn.com`，
  沒有 API key 時它回 HTTP 200、回一張真的 PNG、大小也正常 ——
  但圖上印著「API KEY REQUIRED」的浮水印。用眼睛看才看得出來。
  改成 Esri 的灰階 canvas，免金鑰、無浮水印，標註 Esri／HERE／OSM。
- 地圖不裝 Leaflet。雷達圖就是一格一格的圖磚，自己算 x/y/z 再擺
  `<img>` 就好，一個地圖套件比整個擴充功能還大。
- 拉大才載圖磚。預設大小一張圖都不該抓 —— 那是每開一個新分頁都要付的網路成本。
- **回波的平滑要關掉。** `smooth=1` 好看，但那個平滑是每張圖磚各自算的，
  相鄰兩張在接縫兩側對不起來 —— 畫面上是一條筆直的斷線，剛好落在圖磚邊界。
  `smooth=0` 顆粒粗一點，但是連續的。
- **RainViewer 的回波只到 z7。** 再放大它回的是一張寫著
  「Zoom Level Not Supported」的灰卡，而且是 HTTP 200、正常的 256×256 PNG、
  每張都剛好 1370 位元組 —— 狀態碼和大小都看不出來。超過就抓 z7 再放大貼，
  底圖繼續變細、回波變糊，但蓋的還是同一塊地。

## 4. 音樂控制器 ← 完成（(a) 版）

偵測瀏覽器正在播放的媒體，控制播放／下一首，卡片背景直接用該媒體的封面。

**這一項要先講清楚做得到什麼**，因為它跟前三項不一樣，不是工多工少的問題：

- 做得到：`chrome.tabs.query({ audible: true })` 拿到「正在發出聲音的分頁」，
  有標題和 favicon；`chrome.tabs.update({ muted })` 可以靜音；點一下切過去那個分頁。
  這些只要 `tabs` 權限。
- **做不到（不加碼的話）**：封面圖、曲名、演出者、播放／暫停／下一首。
  瀏覽器沒有給擴充功能「全域媒體控制」的 API。要拿到那些，得對每一個
  播放中的網站注入 content script 去讀 `navigator.mediaSession`，
  那要 `<all_urls>` 的 host permission —— 上架審查會逐條問，
  而且「下一首」還得去模擬各家網站自己的按鈕，YouTube 一改版就壞。

所以這一項有兩個版本要你選：
**(a) 只用 `tabs`**：列出正在播放的分頁、靜音／取消靜音、點一下切過去。封面用 favicon。
**(b) 加 `<all_urls>`**：真的封面與真的播放控制，但只在我們逐站支援的網站上有效，
且上架時要為那個權限提出理由。

做的是 (a)：列出正在發聲的分頁、靜音／取消靜音、點一下切過去，
卡片底圖用網站圖示放大糊掉。輪詢兩秒一次 —— 沒有 onAudibleChanged 這種事件，
而那是問瀏覽器自己記憶體裡的清單，不是網路請求。

要 (b) 的話要加的東西：`<all_urls>` host permission、逐站的 content script
去讀 `navigator.mediaSession`、以及每一站自己的「下一首」按鈕怎麼按。
上架審查會為那個權限逐條問，而且對方一改版就壞。


## 跨裝置（做到一半）

**已經有的**：設定與版面走 `chrome.storage.sync` —— 同一個 Edge 帳號登入的兩台機器
本來就會同步。進度（待辦、筆記、番茄鐘紀錄）走 `chrome.storage.local`，不跨裝置，
因為 sync 每項 8KB、總計 100KB，那些東西會長大。

**這一輪做的**：`src/lib/snapshot.ts` —— 設定加工作區打包成一個 JSON，
設定裡可以匯出成檔案、從檔案還原。跨瀏覽器、跨帳號都能用，代價是自己搬檔案。
照片不在裡面（IndexedDB，一張好幾 MB）。

**還沒做的：登入 Google 存到雲端**。快照層已經是那件事的貨物，缺的是運送：

1. 到 Google Cloud Console 開一個專案，建立 OAuth 2.0 用戶端 ID（類型：網頁應用程式），
   授權的重新導向 URI 填 `https://<擴充功能 ID>.chromiumapp.org/`。
2. 擴充功能 ID 在上架前不固定 —— 要嘛先上架拿到正式 ID，要嘛在 manifest 裡放一組
   `key` 把 ID 釘死。這一步沒有替代方案，Google 那邊要認得這個 ID。
3. manifest 加 `identity` 權限與 `https://www.googleapis.com/*` 的主機權限。
4. 程式面：`chrome.identity.launchWebAuthFlow()` 拿 token（Edge 也支援，
   `getAuthToken()` 只有 Chrome 有），快照上傳到雲端硬碟的 `appDataFolder` ——
   那是每個應用自己的隱藏資料夾，使用者的檔案清單看不到它，也不佔可見空間。

第 1、2 步只有帳號的主人做得到，程式這邊等那組用戶端 ID 就能接上。

### 語系

這一輪只出繁體中文和英文。`ja` 與 `zh_CN` 移除了 —— 兩邊各缺 94 個內容鍵，
留著只會讓那些使用者拿到中英混雜的畫面。

`default_locale` 維持 `zh_TW`，這是刻意的：`isEnglish()` 判斷的是瀏覽器介面
語言而不是解析後的語系，所以法文使用者仍然會去要 `jq_*`（節氣），而英文版
沒有那 24 個鍵（它的外環走月名）。改成 `en` 當後備，他們的外環會整圈空白。
